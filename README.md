This project explores 1.13 million recipe reviews from Food.com using PySpark and builds a simple content-based recipe recommender on top of them. I cleaned the data (dropping missing values and excluding unrated reviews), ranked recipe tags with a weighted rating so small samples don't skew the results, grouped recipes with K-Means, and used TF-IDF on tags and ingredients with cosine similarity to suggest dishes similar to one you already like. It's written in Google Colab as part of my HND in Artificial Intelligence, and the next step is adding ALS collaborative filtering for personalised recommendations.
